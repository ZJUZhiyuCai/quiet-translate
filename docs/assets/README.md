# Demo assets

These screenshots were captured from Quiet Translate 1.1.0 running on the original `tests/fixtures/article.html` page and its text workspace. The translations were produced by GLM 5.3 Flash through an OpenAI-compatible API; the selection image explicitly shows a local cache hit. They contain no personal browser tabs or API credentials.

- `bilingual.png`: translations beneath unchanged English passages.
- `selection.png`: a pinned selection card on the same article.
- `workspace.png`: original text and a completed long-text translation.

The fixture and screenshots are included under the repository's MIT license. They are product demonstrations, not customer testimonials or measurements of every API provider.
